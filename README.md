# How to run the application

### 1. Installation
Ensure that you have **VC Code** IDE, **Node.js**, and **Angular CLI**, installed on your computer:

- For more information related to VS Code installation and setup, please check out the [VS Code Setup and Installation](https://code.visualstudio.com/download) website.

### 2. Clone `GitHub` repository

Clone the project [fn-systems-site](https://github.com/functionsystems/fn-systems-site.git) from Github repository into your local repository . For more information about how to clone the GitHub repository, see [Cloning GitHub repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository).


### 4. Run the project

- Navigate to the folder where your cloned project is saved
- Open the folder
- Look for html file with file-mane html.index
- Double-click the file,  then the file will be opened in the browser, depanding on which browser has been set as default in you computer.
